# ここに入っているもの

**公式素材ではありません。** 素材の差し替え口（`art/source.ts`）が
本当に効くかを確かめるためだけの、自作の色板です。

| ファイル | 何に当たるか | 見た目 |
| --- | --- | --- |
| `tile-grass.png` | くさむらのマス | マゼンタの市松 |
| `species-pidgey.png` | ポッポ | 水色に黒枠 |
| `player.png` | 主人公 | 黄色い四角 |

**わざと派手にしてある。** 差し替わったかどうかを一目で決められないと、
「入れたのに変わらない」のか「変わったが似ている」のかが分からない。

## 公式素材はここにも入りません

このリポジトリは公開なので、公式のドット絵を置くと公衆送信になる
（`docs/game-plan.md` §10）。`.gitignore` は `assets/` を丸ごと止めていて、
**この `placeholder/` だけを例外にしてある** ―― 中身が自作だから。

手元の公式素材は `assets/` の直下など、無視される場所に置いて、
設定画面の「え（そざい）」から入れる。名前の一覧は `npm run art:names`。
