# 第4版の設計 ― 厚みを出す

第3版（N〜S）で「一通り遊べる」ところまで来た。マップ24枚、種族51、技70、
4つのジムからリーグ、クリア後の再挑戦まで揃っている。

この版で狙うのは **幅を広げることではなく、いまあるものを厚くすること**。
データを突き合わせると、「枠組みは作ったのに中身が薄い」場所がはっきり見える。

| 見つかった薄さ | 実態 |
|---|---|
| **積み技が実質ゼロ** | `ai.js` に積み技の評価ロジックがあるのに、自分を上げる技が `かたくなる` だけ |
| **進化系統の 7割が2段目で終わる** | 22系統中16系統。3段完成しているのは御三家＋3系統だけ |
| **タイプの偏りが激しい** | ひこう13 に対して はがね1、こおり2、かくとう2、エスパー2、いわ2 |
| **ジムリーダーの3/4が単一系統** | マチス＝ピカチュウ系のみ、イワオ＝イシツブテ系のみ、コトリ＝ヒトモシ系のみ |
| **とくせいが無い** | 51種すべて |
| **天候が無い** | 過去のタスクでは「完了」扱いだが、コードに存在しない |
| **技のエフェクトが1種類** | ほのおもみずも「白く3回点滅」で同じ |
| **記録が playTime だけ** | 歩数も戦闘回数も数えていない |
| **ハナカゴシティが町として未完成** | そらをとぶ の行き先なのに、復帰地点もPCもショップも無い |

**ジムリーダーが単一系統なのは、リーダーの手抜きではなくタイプ在籍数が足りないからだ。**
いわタイプは2種（イシツブテ・ゴローン）しかなく、それは同じ系統の前後でしかない。
つまり **種族を増やすことが、そのまま戦闘の厚みに直結する**。ここが第4版の背骨になる。

## Phase T ― 穴を塞ぐ

第3版でこぼれたもの。どれも小さいが、放置すると次の作業の土台が歪む。

| # | 内容 | 理由 |
|---|---|---|
| **T-1** | **ハナカゴシティに センターとショップを1枚ずつ足す** | `fly` の行き先なのに `respawn` も PC も無い。`cave1→cave2→ハナカゴ→ボレイどうくつ→gym4→route3→リーグ` という **Lv24〜48 の最長区間を、ニビで買った物資だけで踏破**することになっている。ゴーストジムで全滅するとニビまで戻される |
| **T-2** | **積み技を3つ足す**（`つるぎのまい` こうげき+2 / `めいそう` とくこう・とくぼう+1 / `こうそくいどう` すばやさ+2） | `ai.js` の `statusScore` に「序盤に積むほど元が取れる」という評価がすでに書いてある。**技を足すだけで既存のAIコードがそのまま動く**。追加実装ゼロで戦術の軸が1本増える |
| **T-3** | **新エリアにぬしを2体置く** | ぬしは4体（1ばんどうろ・トキワのもり・おつきみやま・伝説の間）。Phase R で足したハナカゴ周辺とボレイどうくつには1体もいない。既存の `statics` にデータを足すだけ |

T-2 は **30分で終わって効果が最大**なので、何をおいても最初にやる。

## Phase U ― 種族の拡張（51 → 68種）

### なぜ増やすのか

タイプ別の在籍数を数えると、上下で6倍以上の開きがある。

```
13 ひこう  █████████████
10 ノーマル █████████
 9 みず   █████████
 6 でんき  ██████
 6 くさ   ██████
 5 ほのお  █████
 5 どく   █████
 5 むし   █████
 4 じめん  ████
 3 ゴースト ███
 2 いわ   ██   ← イシツブテとゴローン（同じ系統の前後）
 2 こおり  ██
 2 かくとう ██
 2 エスパー ██
 2 ドラゴン ██
 2 あく   ██
 2 フェアリー██
 1 はがね  █    ← ルカリオだけ
```

**いわジムのリーダーが2匹とも同じ系統なのは、いわタイプが2種しか居ないからだ。**
選びようがない。ゴーストジムも同じ（ヒトモシ→ランプラー）。
つまりこの偏りは、そのままジム戦・リーグ戦の単調さとして表に出ている。

### U-1 ― 行き止まりの系統を完成させる（10種）

**これが一番安くて一番効く。** 22系統のうち16系統が2段目で止まっている。
そこに3段目を1体足すだけで、系統がひとつ完成し、タイプの穴も同時に埋まる。

| いまの終点 | 足す3段目 | タイプ | 埋まる穴 |
|---|---|---|---|
| ゴローン (75) | **ゴローニャ** (76) | いわ／じめん | **いわ** 2→3 |
| キルリア (281) | **サーナイト** (282) | エスパー／フェアリー | **エスパー・フェアリー** 2→3 |
| ランプラー (608) | **シャンデラ** (609) | ゴースト／ほのお | **ゴースト** 3→4 |
| ジヘッド (634) | **サザンドラ** (635) | あく／ドラゴン | **あく・ドラゴン** 2→3 |
| パモット (922) | **パーモット** (923) | でんき／かくとう | **かくとう** 2→3 |
| モココ (180) | **デンリュウ** (181) | でんき | 系統の完成 |
| ゴルバット (42) | **クロバット** (169) | どく／ひこう | 系統の完成 |
| ピジョン (17) | **ピジョット** (18) | ノーマル／ひこう | 序盤の代表格 |
| ムクバード (397) | **ムクホーク** (398) | ノーマル／ひこう | 3ばんどうろの主力 |
| ヒノヤコマ (662) | **ファイアロー** (663) | ほのお／ひこう | 3ばんどうろの主力 |

上5体だけで **6つのタイプの穴が埋まる**。下5体は穴埋めにはならないが、
「育てたら最終形になる」という当たり前の手触りを揃えるために入れる。

> **注意:** 下の3体（ピジョット・ムクホーク・ファイアロー）はどれも ひこう を足す。
> ひこうは既に13種で最多なので、偏りをこれ以上広げたくなければ **この3体は後回しでよい**。
> その場合 U-1 は7種になる。

### U-2 ― 足りないタイプに新しい系統を入れる（7種）

U-1 のあとも **はがね3・こおり4** はまだ薄い。ここは新規系統で埋める。

| 系統 | タイプ | 出現させる場所 | 埋まる穴 |
|---|---|---|---|
| **テッシード → ナットレイ** (597→598) | くさ／はがね | ボレイどうくつ | **はがね** 1→3 |
| **ウリムー → イノムー** (220→221) | こおり／じめん | おつきみやま ちか | **こおり** 2→4 |
| **ワンリキー → ゴーリキー → カイリキー** (66→67→68) | かくとう | おつきみやま １かい | **かくとう** 3→6 |

かくとうを3体入れるのは、**ゴーストジム対策の軸**を作るため。
いまゴースト技に有利を取れるのは あく（モノズ系）だけで、選択肢が無い。

### 拡張後のタイプ分布

```
17 ひこう  （+4：3体を後回しにすれば 14）
12 ノーマル
 9 みず
 8 くさ / でんき
 7 ほのお / じめん
 6 かくとう / どく
 5 むし
 4 こおり / ゴースト
 3 いわ / エスパー / フェアリー / あく / ドラゴン / はがね
```

最少が 1 → 3 になり、**どのタイプでもパーティを組める**ようになる。

### 作業の段取り

ドット絵17枚が全体のボトルネックになる。第1版の教訓（「作画で全部が止まる」）を
そのまま適用する。

1. **先にデータだけ入れる。** スプライトは `placeholderSprite(id)` のまま。
   `tests.html` の整合性チェックはこの時点で全部通る。
2. **エンカウント表とトレーナーの手持ちを差し替える。** ここまでで遊べる状態になる。
3. **ドット絵は1体1コミットで後から差し替える。** `tools/spriteedit.html` を使う。
   エンジンには一切触らない純増分なので、途中で止めても壊れない。

### 併せてやること

- **ジムリーダーの手持ちを組み直す。** いわジムを ゴローニャ＋ウリムー、
  ゴーストジムを シャンデラ＋ゲンガー系 のように**別系統の2匹以上**にする
- **エリート4とチャンピオンの手持ちも見直す。** いまは在籍数の都合で
  ノーマル／ひこうに寄っている
- **図鑑の総数が変わる。** `dexReady10 / 20 / All` のしきい値と、
  はかせの報酬（ひかるおまもり）の条件を再確認する

## Phase V ― とくせい

**51種すべてに特性が無い。** ポケモンらしさで、いま最大の未実装要素。

### 方針

全種に付けない。**20種ほどに絞る**。全部に付けると
「持っていて当たり前」になり、個体を選ぶ理由にならない。

### `battle.js` に開けるフック点

いまの戦闘進行は「メッセージ→命中→ダメージ→追加効果→ターン終了」という
一本道なので、特性のためにフックを4つ足す。

| フック | 呼ばれる瞬間 | 使う特性の例 |
|---|---|---|
| `onSendOut` | 場に出た直後 | いかく（相手こうげき−1） |
| `onModifyDamage` | ダメージ計算の直後・適用の前 | もうか・げきりゅう（HP1/3以下でタイプ強化）、ふゆう（じめん無効） |
| `onAfterHit` | 被弾したあと | せいでんき・ほのおのからだ（接触で状態異常） |
| `onEndOfTurn` | ターン終了時 | あめうけざら（天候と組む） |

### 入れる特性

| 特性 | 効果 | 付ける種族 |
|---|---|---|
| もうか / げきりゅう / しんりょく | HP1/3以下で該当タイプの技が1.5倍 | 御三家3系統 |
| **いかく** | 場に出たとき相手のこうげき−1 | ラッタ、グラエナ、カイリキー |
| ふゆう | じめん技が効かない | シャンデラ、ゴースト系 |
| せいでんき | 接触されると30%でまひ | ピカチュウ系、パモ系 |
| ほのおのからだ | 接触されると30%でやけど | ヒトモシ系 |
| がんじょう | 一撃で倒されない（HP満タンなら1残る） | イシツブテ系、ハガネール |
| すいすい | あめのとき すばやさ2倍 | みず系（Phase W と組む） |

**`いかく` が入ると、交代に初めて戦術的な意味が生まれる。**
だから Phase X の「AI交代」と同時に入れると効果が倍になる。

## Phase W ― 天候

過去のタスク一覧では「完了」になっているが、`grep` してもコードに存在しない。

| 天候 | 効果 | 発生源 |
|---|---|---|
| **あめ** | みず技1.5倍／ほのお技0.5倍 | 技 `あまごい` |
| **にほんばれ** | ほのお技1.5倍／みず技0.5倍 | 技 `にほんばれ` |
| **すなあらし** | いわ／じめん／はがね 以外は毎ターン 最大HP/16 のダメージ | 技 `すなあらし` |

- `ctx.weather = { kind, turns }` を持ち、`endOfTurn` で減らすだけ
- ダメージ補正は `formulas.js` の `damage()` に1行足す
- **ジムリーダーが場を作ってくる**ようにすると、ジム戦が殴り合いから読み合いになる

特性（`すいすい` など）より軽いので、**Phase V の前に入れておくと V が楽になる**。

| # | 内容 | 詳細 |
|---|---|---|
| **X-1** | **変化技の幅を広げる** | いまの11種は「状態異常5・能力ダウン4・能力アップ1・回復1」と偏っている。`みがわり`・`まもる`・`どくどく` を足すと、**受け型（モスノウ・ラグラージ・ナットレイ）に存在意義が生まれる** |

## Phase Y ― 見た目

**ここが、いま一番「粗く」見える。**

### Y-1 ― 技ごとのエフェクト（最優先）

すべての技が「白く3回点滅＋横に4px揺れる」で同じ。
`かえんほうしゃ` も `ハイドロポンプ` も見分けがつかない。

全70技に個別演出は要らない。**タイプ別に9種類**用意すれば印象が変わる。

| タイプ | 演出（すべて矩形と円だけで描ける） |
|---|---|
| ほのお | 赤〜橙の粒が下から立ちのぼる |
| みず | 青い横波が3本、左から右へ走る |
| でんき | 黄色いギザギザが縦に落ちる |
| くさ | 緑の葉が回転しながら飛ぶ |
| かくとう | 白い衝撃線が中心から放射 |
| こおり | 白い結晶が上から降る |
| どく | 紫の泡が浮かぶ |
| エスパー | 桃色の同心円が広がる |
| その他 | いまの白点滅（既存のまま） |

既存の Canvas 描画で完結し、**アセットは1枚も増えない**。
投入時間あたりの見栄えの変化が一番大きい。

### Y-2 ― 背面スプライト（最終進化12種だけ）

第1版で「作らない」と意図的に決めた項目だが、いまは自分側も正面を向いている。
全種は大仕事なので、**最終進化の12種だけ**描くと、主力で戦っている間の絵が締まる。
無い種族は今まで通り正面＋反転でフォールバックする。

### Y-3 ― 戦闘導入の格を分ける

いまワイプは1種類。BGM は既に `battle / boss / trainer / legend` と分けてあるので、
**視覚だけが追いついていない**。ぬし戦・ジムリーダー戦・伝説戦で導入演出を変える。

## Phase Z ― 記録と、長く遊ぶ仕掛け

### Z-1 ― プレイ統計とトレーナーカード

`state` に入っている記録は **`playTimeMs` だけ**。以下はカウンタを足すだけで取れる。

- 歩いた歩数 ／ 戦った回数 ／ 捕まえた数 ／ 逃げられた数 ／ 使ったボールの数
- 一番長く一緒にいるポケモン（`metLv` と現在Lvの差で出せる）
- 最初に捕まえたポケモンと、その場所（`dex.where` は既にある）

これを**トレーナーカード1画面**にまとめる。`MenuScene` にバッジ表示があるので、
そこを1画面に育てる形。**最後まで飽きない報酬**になる。

### Z-2 ― 殿堂入りの記録を残す

`hallOfFameCount` は数えているだけで、**中身を保存していない**。
何回目にどのパーティ（種族・Lv・ニックネーム）で勝ったかを残し、
「でんどうのま」で見返せるようにする。セーブに配列を1本足すだけ。

### Z-3 ― 色違い

`pixelArt.js` は既にパレット方式なので、**色相を回転させる関数を1つ足すだけ**。
1/512 程度で出現させ、図鑑にマークを付ける。
クリア後の野生狩りに、もう一つの目的が生まれる。

### Z-4 ― れんせんタワー

図鑑をコンプすると `objective()` は
「そだてやや つりざおで、じっくり そだてよう」で終わる。**その先の目的が無い。**

10連戦をレベル固定・途中回復なしで挑む施設を1部屋足す。

- 育成の成果を試す**明確なゴール**ができる
- 既存のトレーナー戦の仕組みをそのまま使う（新規実装がほぼ不要）
- 連勝記録を Z-1 の統計に残せば、繰り返す理由になる

## 検証

- `tests.html` に足すもの
  - **タイプ在籍数の下限** ― どのタイプも3種以上いる（U で入れた保証を固定する）
  - **進化系統の完成度** ― 2段目で止まっている系統の一覧を出す（意図的なものだけ残す）
  - **とくせいの整合** ― 全 `ability` が実装済みのフックに対応している
  - **積み技の存在** ― 上昇量+2の技が各方面（こうげき・とくこう・すばやさ）に1つ以上ある
  - **天候の整合** ― 天候を作る技が全種類ぶん存在する
- **通しプレイの自動検証を1本作る。** いま 4401件のテストはすべて単体検証で、
  「最初から殿堂入りまで実際に歩いて勝てるか」は誰も確かめていない。
  Phase R でレベルを大きく引き上げたので、**いま特に価値がある**。
  Playwright で御三家選択→4バッジ→リーグ制覇までを自動走行させ、
  詰みとレベルカーブの破綻を検出する。
- `dist/datasheet.html` を焼き直し、「いまの穴」が空のままであることを確認する

## 進める順番

```
T（半日）→ U-1（2〜3日）→ W（1日）→ V（2〜3日）→ X（2日）→ Y-1（1〜2日）→ U-2 → Z
```

**T-2（積み技3つ）を最初に。** 30分で終わり、既存のAIコードが即座に活きる。

**U-1 が全体の鍵。** タイプの穴が埋まらないと、V（とくせい）で面白い特性を配る先も、
X（ジムリーダーの厚み）で組むパーティも作れない。ここを先に通す。

**W → V の順にする。** 天候のほうが軽く、`すいすい` のような
天候と組む特性を後から足せるようになる。逆順だと V をやり直すことになる。

**Y-1 はどこに挟んでもよい。** 戦闘ロジックに一切触らないので、
他のフェーズと並行できる。手が空いたときの逃げ場として置いておく。

**U-2 と Z は打ち切り可能。** T〜Y だけでも完結した状態は保てる。

### ドット絵の扱い

U で17枚、Y-2 で12枚、合わせて **29枚**が必要になる。
これが全体のボトルネックなので、**データとプレースホルダを先に入れて遊べる状態を作り、
作画は独立したコミットで後から流し込む**。第1版と同じやりかたで、これは効いた。
