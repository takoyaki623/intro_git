# 種族の再編 ― 世代を散らす

## なぜやるか（好みの問題ではなく、遊びの穴）

いま25種はすべてカントー、しかも序盤ルート帯だけ。その結果:

**技は18タイプすべて揃っているのに、ポケモンは10タイプ分しかいない。**

| | 状況 |
|---|---|
| わざ | 18タイプすべてに存在（42種） |
| ポケモン | **10タイプのみ**。ひこう7・みず6・どく5・ノーマル4・くさ3・ほのお3・むし3・でんき2・いわ2・じめん2 |
| **種族がゼロのタイプ** | **こおり／かくとう／エスパー／ゴースト／ドラゴン／あく／はがね／フェアリー（8タイプ）** |

タイプ相性を実装して、UIにタイプ色まで用意してあるのに、**相性表の半分が死んでいる**。
「こうかは ばつぐんだ！」の駆け引きが、実質 みず・ほのお・くさ・でんき の四角形しか回っていない。

原因ははっきりしていて、**カントーの序盤ポケモンだけで組んだから**です。
初代にはあく・はがね・フェアリーが存在せず、こおり・ドラゴン・ゴーストは終盤にしかいない。

つまり「いろいろな世代を入れたい」という要望と、
「死んでいる8タイプを起こす」という設計上の必要が、**同じ方向を向いています**。

## 方針

### 1. 1つの役割は1つの世代から取る

「序盤の鳥」「序盤の小動物」「洞窟のコウモリ」といった**役割**ごとに、担当世代を分ける。
ランダムに混ぜるのではなくこうすると、多様性が構造として保証される。

### 2. 1エリアに同じ世代を2系統まで

各エリアの遭遇表に、必ず**3世代以上**が混ざるようにする。
図鑑の総数より、**歩いていて出てくる顔ぶれ**のほうが体感に効く。

### 3. 空いている8タイプは「2タイプ持ち」で効率よく埋める

| 系統 | 世代 | タイプ | 埋まるもの |
|---|---|---|---|
| ラルトス→キルリア→サーナイト | 3 | エスパー・フェアリー | **エスパー＋フェアリー** |
| リオル→ルカリオ | 4 | かくとう→かくとう・はがね | **かくとう＋はがね** |
| モノズ→ジヘッド | 5 | あく・ドラゴン | **あく＋ドラゴン** |
| ヒトモシ→ランプラー | 5 | ゴースト・ほのお | **ゴースト** |
| ユキハミ→モスノウ | 8 | こおり・むし | **こおり** |

**5系統で8タイプすべてが埋まる。** どれも人気があり、ドット絵にしたときのシルエットも立つ。

## 既存25体をどうするか（唯一、判断を仰ぎたいところ）

**案A（推奨）: 1体も消さない。他世代を26体足して計51体。**

- 既存のカントー勢は残すが、**遭遇表での重みを下げて脇役に回す**（各エリア 10〜15%）。
  出現しなくなるわけではないので図鑑は埋まるし、作画済み25体を1つも捨てない。
- 図鑑に占めるカントー比は約半分になるが、**各エリアの主役は他世代**になるので、
  歩いている間はずっと知らない顔が出てくる。

**案B: カントーを14体に絞る（ポッポ系・コラッタ系・キャタピー系・ズバット系・コダック の11体を削除）。計40体。**

- 図鑑のカントー比 35%。すっきりするが、**作画済み11体分の絵を捨てる**。

### 推奨は A。理由は非対称性

**A から B へは、あとからデータを消すだけでいつでも移れる。B から A へは戻れない**（絵を描き直すことになる）。
迷うなら、消さないほうを先に取っておくのが安い。

## 御三家 ― ここは3世代の混成にする

最初に選ぶ3体が全部カントーだと、「カントーのゲーム」という第一印象が確定してしまう。
**ゲームを始めて30秒で世代の広さが伝わる**ので、ここは変える価値がある。

| | 系統 | 世代 | タイプの変化 | 進化 |
|---|---|---|---|---|
| くさ | モクロー → フクスロー → ジュナイパー | **7（アローラ）** | くさ・ひこう → **くさ・ゴースト** | Lv17 / Lv34 |
| ほのお | ヒトカゲ → リザード → リザードン | **1（カントー）** | ほのお → ほのお・ひこう | Lv16 / Lv36 |
| みず | ミズゴロウ → ヌマクロー → ラグラージ | **3（ホウエン）** | みず → **みず・じめん** | Lv16 / Lv36 |

- ヒトカゲ系は**作画済みで一番手が入っている**ので残す。カントー代表として過不足ない。
- 最終形が **ゴースト**（ジュナイパー）と **じめん**（ラグラージ）を持つので、
  御三家だけで死んでいたタイプが2つ起きる。
- ラグラージは**でんきが無効**になるので、最初のジム（トキワジム＝でんき）との相性が
  「みずを選ぶと楽」から「みずを選ぶと圧勝」に変わる。
  → トキワジムのマチスに **じめん半減の手** を1体入れてバランスを取る。

**フシギダネ系・ゼニガメ系は消えません。** クリア後の交換NPC（設計v2のPhase L）で入手できます。
選ばなかった御三家2種と合わせて、**カントー御三家の入手そのものがクリア後の目的**になります。

## 技術的に必ずやること

### 1. 図鑑番号を全国図鑑に揃える（セーブ移行が必要）

現状の `id` は不統一で、**実際の全国図鑑番号とずれているものがある**:

| 種族 | 現在の id | 正しい全国図鑑 |
|---|---|---|
| キャタピー / トランセル / バタフリー | 14 / 15 / 16 | **10 / 11 / 12** |
| ポッポ / ピジョン | 10 / 11 | **16 / 17** |
| コラッタ / ラッタ | 12 / 13 | **19 / 20** |
| ピカチュウ | 17 | **25** |

他世代を足すと必ず全国図鑑番号を使うことになるので、**ここで揃えないと恒久的に破綻する**
（例: 新しく足す「16番」がポッポとムックルで衝突する）。

- `MonSave.id` と `dex.seen` / `dex.caught` に生の id が入っているので、
  **セーブのマイグレーションを1本足す**（`MIGRATIONS` の仕組みは実装済み）。
- 旧 id → 新 id の対応表を書いて `version: 2 → 3` で変換する。

### 2. `gen` フィールドを足す

```js
722: { id:722, gen:7, name:'モクロー', types:['くさ','ひこう'], … }
```

図鑑にすでに**絞り込み機能がある**（Phase F で実装済み）ので、
**「世代で絞る」を1項目足すだけ**で、集めた世代の広がりが見えるようになる。

### 3. 進化方式の簡略化（正直に書いておく）

エンジンは `level` と `stone` しか解釈しない。本来なつき進化・通信進化のものは、
**v1ではレベル進化で代用する**。

| 種族 | 本来 | このゲーム |
|---|---|---|
| リオル → ルカリオ | なつき（昼） | Lv30 |
| パモット → パーモット | なつき＋バトル20回 | 出さない（パモットまで） |
| ガントル → ギガイアス | 通信交換 | 出さない（ガントルまで） |
| ランプラー → シャンデラ | やみのいし | 出さない（ランプラーまで） |
| ジヘッド → サザンドラ | Lv64 | 出さない（ジヘッドまで） |

**最終進化まで出さない系統がある**のは意図的で、Lv38 のリーグに対して
BST 600 級が並ぶと壊れるため。「なつき度」を足したくなったら Phase M で入れて差し替える。

### 4. 作画（このフェーズの最大コスト）

**+26体**。ここが全体のボトルネックになる。従来どおりの進めかたで潰す:

1. `placeholderSprite()` のまま**先に全データを通す**。エンカウント・進化・リーグまで
   遊べる状態を作ってから、絵に取りかかる。
2. 作画は**1体1コミット**の独立作業。ゲームの進行を止めない。
3. **進化前後は骨格を共有**して描く（色替え＋パーツ追加）。26体ぶんの労力は実質18体ぶんになる。
4. コミット `673f41b` で入れた**ドット絵エディタ**をここで使い倒す。

## テストに足すもの

これは「二度と偏らないようにする」ための仕掛けなので、必ず入れる。

```js
section('種族 ― タイプと世代のカバレッジ');
// 1. 18タイプすべてに、最低1つの種族が存在する      ← 今回の穴を再発させない
// 2. 18タイプすべてに、威力40以下と威力75以上の技が両方ある
// 3. どの世代も、少なくとも1系統は存在する
// 4. 各エリアの遭遇表に、3世代以上が含まれる          ← 「1エリア2系統まで」の担保
// 5. すべての id が全国図鑑番号と一致し、重複がない
// 6. すべての evolution.to が存在し、進化レベルが親のレベル帯より上
// 7. セーブ移行: version 2 のセーブを読んで、旧idが正しく変換される
```

4番と1番が、**今回の要望をコードに焼き付ける部分**です。
以後どれだけ種族を足しても、テストが偏りを検出します。
