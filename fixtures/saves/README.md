# 過去版のセーブ

**マイグレーションが壊れていることに気づくのは、常に手遅れになってから。**
（[`../../docs/design/save-data.md`](../../docs/design/save-data.md) §5）

ここに置いた各版のセーブが、CI で毎回**最新版まで引き上がること**を確かめる。
スキーマの版を上げたら、**そのときのセーブを1件ここに足す。**

| ファイル | 版 | いつ |
| --- | --- | --- |
| `v1.json` | 1 | v0.5（BP と施設の記録だけ） |
| `v2.json` | 2 | v0.6（トーナメントの記録が加わった） |
| `v3.json` | 3 | v0.9（世界の状態が入った） |
| `v4.json` | 4 | v0.10（共通ボックスと現在地方） |

検証は `packages/core/test/save.test.ts` が行う。
