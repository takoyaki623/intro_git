# 第3版 設計 ― 死蔵の解放と、育成の中身

第2版で旅にゴール（ポケモンリーグ・殿堂入り）が入った。
この設計は**中身の密度**を上げる。狙いは3つ。

1. **作ったのに遊べないものを解放する**（どうぐ5個・わざ6つが誰にも届いていない）
2. **育成に中身を入れる**（51種のうち30種は覚える技が4つ以下で、選ぶ余地がない）
3. **旅を長くする**（バッジ2個でリーグに着いてしまう）

対象ブランチ: `claude/pokemon-style-game-s4v9rf`

---

## 0. 全体の見取り図

| Phase | 内容 | 依存 | 規模 |
|---|---|---|---|
| **N** | 死蔵の解放（どうぐ5個の配置・ぬしの演出） | なし | 小 |
| **O** | **技と学習セットの再設計** | なし | 大 |
| **P** | 情報の見せかた（相性予測・ランク矢印・戦闘背景・図鑑） | なし | 中 |
| **Q** | クリア後の再挑戦（リーグ再戦・ライバル再戦・ぬし復活） | K(済) | 中 |
| **R** | 世界を広げる（3つめ・4つめのジム） | O | 大 |
| **S** | 余力（伝説のぬし・進化のやり直し） | Q | 小 |

N・O・P は互いに独立なので、どこから着手してもよい。
**R は O に依存する** ―― ジムリーダーの手持ちを組むには、まともな学習セットが要る。

各 Phase の終わりに遊べる状態を残し、`tests.html` を全green にしてから `dist/` を焼き直す。

**やらないもの**: ダブルバトル、とくせい、通信交換。

## Phase N ― 死蔵の解放

### N-1. どうぐ5個が入手不能

`dist/datasheet.html` の「いまの穴」が指摘しているとおり、

> むしよけスプレー・あなぬけのヒモ・オボンのみ・たべのこし・きあいのハチマキ は、
> 定義はあるのに落ちてもいないし売ってもいません。

これは **Phase H で作った「もちもの」「スプレー」「あなぬけ」が丸ごと死んでいる**ということ。
`battle.js` の `pinchHeal` / `endTurnHeal` / `endure`、`encounter.js` の `repelSteps`、
`world.js` の `lastEntrance` ―― どれも実装もテストも通っているのに、プレイヤーは一生触れない。

**配置**（買える・拾える・もらえるの3経路をそれぞれ用意する）

| どうぐ | 店 | 落ちもの | もらう |
|---|---|---|---|
| むしよけスプレー | 両マート（`badge_denki` 後） | おつきみやま1F 入口 | — |
| あなぬけのヒモ | 両マート | おつきみやま地下 | — |
| オボンのみ | ニビの店のみ | トキワのもり | ぬし（もり）撃破 |
| たべのこし | — | おつきみやま地下 最奥 | ぬし（ちか）撃破 |
| きあいのハチマキ | — | ３ばんどうろ | ぬし（１ばん）撃破 |

**回帰の防ぎかた**: `tests.html` に
「`ITEMS` の全どうぐは、店・落ちもの・会話の `give`・ぬし報酬のどれかに現れる」
という到達性チェックを入れる。以後どうぐを足しても自動で見つかる。

### N-2. ぬしポケモンが「ちょっと強い野生」で終わっている

いま3体（１ばんどうろ Lv10 ライチュウ／もり Lv15 バタフリー／ちか Lv25 ゴローン）いるが、
接触しても普通の野生戦が始まり、倒すと消えるだけ。

- 接触時に専用の前口上 ―― 「ただものではない ○○が こちらを にらんでいる！」
- 画面をひと揺らし（`FieldScene` に既存のシェイクを流用）＋ BGM を `boss` に差し替え
- **撃破・捕獲のどちらでも、もちものを1つ落とす**（上表の「もらう」列）
- 逃げられた場合はフラグを立てない（＝また挑める）。いまの `resume()` の判定はすでにそうなっている

`statics` のエントリに `intro` と `prize` を足すだけで、エンジン側の変更は最小限で済む。

## Phase O ― 技と学習セットの再設計

**この設計のいちばん厚い部分。** 現状を測ったら、想像より深刻だった。

### O-1. 測定結果

```
世代 : 種族数 : 平均技数
 1世代 : 25 : 5.8      ← 元からいたカントー勢
 2〜9世代 : 26 : 3.7   ← Phase I で足した勢
```

| 症状 | 該当数 |
|---|---|
| 覚える技が **4つ以下**（4枠を埋めても選ぶ余地がない） | **30 / 51** |
| 最大威力が 50 以下（終盤で戦力にならない） | 12 |
| 最後の習得が **Lv20 以下**（後半なにも覚えない） | 16 |
| わざマシンを1つも受けない | 10 |
| 攻撃技のタイプが1種類だけ | 3（トランセル・メリープ・ホシガリス） |

原因ははっきりしている。**Phase I で26体を足したとき、種族データの体裁だけ整えて
学習セットは3〜4行で済ませた。** 世代を散らすことが目的だったので、技は後回しにした。
その「後回し」がそのまま残っている。

結果として、追加した26体はどれも**中盤で手が止まる**。
Lv15 で最後の技を覚えたパモを Lv40 まで育てても、技構成は Lv15 のままになる。

### O-2. 技プールの穴

タイプ別に、攻撃技の威力を並べるとこうなっている。

```
くさ    20,25,45,55   ← 最大55。18タイプで唯一、決定打がない
ほのお  40,90         ← 中盤(60〜75)が空
でんき  40,90         ← 同上
こおり  40,90         ← 同上
どく    15,90         ← 同上
エスパー 50,90        ← 同上
じめん  80,100        ← 序盤が空
いわ    50,75         ← 終盤が空
```

**方針**: 各タイプに「序盤 40〜55 / 中盤 60〜75 / 終盤 90〜」の3段を揃える。
穴を埋めるのに必要な新規は10技。

| タイプ | 追加する技 | 威力 | 段 |
|---|---|---|---|
| くさ | リーフブレード | 70 | 中 |
| くさ | ソーラービーム | 120 | 終 |
| ほのお | かえんぐるま | 60 | 中 |
| でんき | スパーク | 65 | 中 |
| こおり | れいとうパンチ | 75 | 中 |
| どく | ヘドロこうげき | 65 | 中 |
| エスパー | サイコカッター | 70 | 中（急所に当たりやすい） |
| じめん | マッドショット | 55 | 序（すばやさ↓） |
| いわ | ストーンエッジ | 100 | 終（急所に当たりやすい） |
| かくとう | ローキック | 65 | 中（すばやさ↓） |

いずれも既存の `effect.kind`（`stat` / `highCrit`）で表現でき、**エンジンの変更は不要**。

### O-3. 学習セットの規格

数を足すだけでは同じことを繰り返す。**満たすべき形を決めて、テストで縛る。**

| # | 規格 | 例外 |
|---|---|---|
| 1 | 最終進化・単段階は **7技以上**、中間進化は **6技以上**、進化前は **5技以上** | コイキング、トランセル |
| 2 | **タイプ一致の攻撃技を1つ以上**持つ | コイキング、トランセル |
| 3 | 最終進化は **威力80以上のタイプ一致技**を1つ持つ | — |
| 4 | 攻撃技のタイプが **2種類以上** | コイキング、トランセル、メリープ |
| 5 | **変化技を1つ以上**持つ（能力変化 or 状態異常） | — |
| 6 | 最終習得レベルが **「進化レベル+10」以上**。最終進化は **Lv40 以上に1つ** | コイキング、トランセル |
| 7 | **わざマシンを2つ以上**受ける | コイキング、トランセル |

例外は `src/data/species.js` に `learnsetExempt: '意図的に弱い'` のような形で**明記**し、
テストはその注記があるものだけ見逃す。「うっかり」と「わざと」を区別できるようにする。

コイキングとトランセルを外すのは、**弱いことに意味がある**ため
（コイキングは育てる山場、トランセルはさなぎ）。メリープの単タイプは電気の伝統に沿う。

### O-4. 孤児になっている6つの技

`とんぼがえり・だましうち・ラスターカノン・マジカルシャイン・チャームボイス・ヘドロばくだん`
は、18タイプ網羅のために作ったが覚える種族がいない。O-3 の再設計で引き取り手を決める。

| 技 | 引き取り手 |
|---|---|
| とんぼがえり | ジュナイパー、モスノウ |
| だましうち | モノズ・ジヘッド、コラッタ系 |
| ラスターカノン | ルカリオ |
| マジカルシャイン | キルリア、モスノウ |
| チャームボイス | ラルトス、メリープ |
| ヘドロばくだん | フシギバナ、（どく枠の補強） |

### O-5. わざマシンを18種に

いま8個。18タイプに1つずつ用意すると、**育成の自由度が一段上がる**（規格7の受け皿にもなる）。
値段は威力に比例させ、店の品揃えはバッジで段階的に開く（既存の `badge_denki` の仕組みを流用）。

### O-6. 作業の進めかた

51種を手で書き直すのは事故が起きやすい。**先にテストを書いて、赤いまま直す。**

1. `tests.html` に O-3 の規格7項目を追加 → **大量に赤くなる**
2. `moves.js` に10技を足す（O-2）
3. 種族を系統ごとに直す（御三家 → 序盤 → 中盤 → 洞窟 → クリア後）
4. 1系統直すたびにテストを回し、赤が減っていくのを確認する
5. 全green になったら、`dist/datasheet.html` を焼いて**目視で通し確認**

datasheet はレベル順に技を並べてくれるので、「Lv30 以降なにも覚えない」が一目で分かる。

## Phase P ― 情報の見せかた

いま戦闘中に見えない情報が多い。**数字を足すのではなく、既にある情報を見せる。**

| # | 内容 | 実装の勘どころ |
|---|---|---|
| **P-1** | **タイプ相性の予測**。技選択画面で技名の右に `▲`(ばつぐん) `▽`(いまひとつ) `×`(こうかなし) | **図鑑に登録済み（`dex.caught`）の相手にだけ出す。** 初見では出さないので、図鑑を埋める動機にもなる。`effectivenessMark(move, foeTypes)` を純関数にして全組合せをテスト |
| **P-2** | **能力ランクの矢印**。HP枠の下に `こうげき▲▲` を小さく。0でないものだけ、最大2つ | `stages` はすでに持っている。表示するだけ |
| **P-3** | **戦闘背景を場所で変える**。いま1種類 | マップに `battleBg: 'grass'｜'cave'｜'water'｜'indoor'` を持たせ、空と地面の色＋地面の模様を差し替える。スプライトは増やさない |
| **P-4** | **図鑑の絞り込みに「みつけた／つかまえた」**を追加し、詳細に**捕まえた場所**を出す | `dex.where` は保存しているのに一度も表示していない |

P-1 は「相性を覚えなくても遊べる」ようにする改善で、いちばん効く。

## Phase Q ― クリア後の再挑戦

いまリーグは Lv30〜36、ライバル最終戦が Lv34〜38。つまり **Lv40 で頭打ち**になる。
Phase L でクリア後の野生を Lv40〜65 に上げたが、**行き先はあっても戦う相手がいない**。
成長曲線は Lv100 まであるのに、そこまで育てる理由がない。

| # | 内容 |
|---|---|
| **Q-1** | **リーグ再挑戦**。`hallOfFameCount` に応じて相手のレベルを `+15 × min(count, 3)` する（最大 Lv51〜81）。賞金も同率で増える |
| **Q-2** | **ライバル再戦**。殿堂入り後、はじまりのむらに現れる。レベルは Q-1 と同じ計算 |
| **Q-3** | **最終進化を野生に混ぜる**。51種のうち22種が進化・交換専用で、図鑑を埋める導線が「自分で育てる」しかない。クリア後テーブルに低weightで混ぜると「野生で出た！」が起きる |
| **Q-4** | **ぬしの復活**。殿堂入りで `boss_*` フラグを消し、Lv50 台で再登場させる |

実装は `trainerBattle(trainer, { levelBonus })` を通すだけで、**AI もデータも触らない**。
Q-1 と Q-2 で `hallOfFameCount` に意味が生まれ、Phase L の図鑑報酬・高レベル野生と
1本の線でつながる。

## Phase R ― 世界を広げる（3つめ・4つめのジム）

**構造上いちばん「未完成」に見えている部分。** バッジは `でんき` と `いわ` の2個だけで、
いわバッジを取った直後にリーグに着いてしまう。ジムを2つ足すと冒険の体感が倍になる。

### 追加するもの

| | 内容 |
|---|---|
| 3つめ | **くさジム**。２ばんどうろの東、池の先（**なみのり必須**）に新しい町を1つ |
| 4つめ | **ゴーストジム**。おつきみやま地下から分岐する洞窟の先 |
| 各ジム | リーダー1人＋道中トレーナー3人＋ジム内トレーナー2人 |

### バッジの効果

3つめ以降で「新しい地形ギミックを解禁する」のは、**既存セーブを壊す危険がある**
（いまの「なみのり」は技を覚えれば使えるので、後からバッジ必須にすると詰む）。
そこで数値ボーナスにする。軽く、既存を壊さない。

| バッジ | 効果 |
|---|---|
| でんき | フレンドリィショップの品揃えが増える（既存） |
| いわ | そらをとぶ（既存） |
| くさ | 野生の**捕獲率 ×1.2** |
| ゴースト | もらえる**経験値 +10%** |

### 順路

```
はじまりのむら → １ばんどうろ → トキワシティ[でんきジム] → トキワのもり
  → ２ばんどうろ → ニビシティ[いわジム] → おつきみやま
  → ★新しい町[くさジム]（なみのり）  → ★分岐洞窟[ゴーストジム]
  → ３ばんどうろ → ポケモンリーグ
```

リーグの入場条件を `badge_iwa` から **4バッジ全部**に変える。
リーグとライバル最終戦のレベルも、伸びた道のりに合わせて Lv42〜50 へ引き上げる。

**規模が大きいので最後に置く。** ここまでの N〜Q だけでも完結した状態は保てる。

## 検証

各 Phase 共通で、**「テストを先に書いて赤くしてから直す」**を守る。

- `tests.html` に足すもの
  - **どうぐの到達性**（N-1）― 全どうぐが店・落ちもの・`give`・ぬし報酬のどれかにある
  - **学習セットの規格7項目**（O-3）― 例外は `learnsetExempt` の注記があるものだけ
  - **技プールの3段**（O-2）― 各タイプに序盤・中盤・終盤の攻撃技がある
  - **相性マークの純関数**（P-1）― 18×18 の全組合せ
  - **バッジとリーグの整合**（R）― 入場条件のバッジが全部実在し、順路上で取れる
- Playwright で、Phase ごとに実機のスクリーンショットを撮って目視する
- `dist/datasheet.html` を焼き直し、**「いまの穴」が空になること**を確認する
  （このページは実データから穴を計算しているので、そのまま完成度の指標になる）

## 進める順番のおすすめ

```
N（半日）→ O（2〜3日）→ P（1日）→ Q（1日）→ R（3日〜）→ S
```

**N を最初に**。作ってあるものが遊べるようになるだけで、体感の密度が上がる。
**O が本体**。ここを直さないと、R でジムリーダーの手持ちを組むときに使える技がない。
**R をやるかどうかは O が終わってから決めてよい** ―― N〜Q だけでも、ゲームは完結している。
