# モンスタークエスト

ポケモン風の簡単なブラウザゲームです。ビルド不要、HTML/CSS/JavaScriptのみで動作します。

## 遊び方

1. `index.html` をブラウザで開く（もしくは `python3 -m http.server` などでローカル配信）
2. 最初の仲間モンスターを3体から選択
3. 矢印キー / WASD でマップを移動
4. 茂み（濃い緑のタイル）を歩くと一定確率で野生モンスターと遭遇し、ターン制バトルが始まる
5. バトルでは「たたかう」で技を選択、「にげる」で逃走を試みる
6. 野生モンスターを倒すと経験値を獲得し、たまるとレベルアップ（HP・攻撃・防御が上昇）

## ファイル構成

- `index.html` — 画面構成（タイトル / マップ / バトル）
- `style.css` — 見た目
- `game.js` — ゲームロジック（マップ移動、エンカウント、バトル計算など）
